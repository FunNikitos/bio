# Экстрактор оформления

Снимает чужую страницу-профиль и превращает её в пресет `profile.v1` с локальными ассетами, эталонными скриншотами и отчётом о том, что переносится вручную.

Нужен, потому что «сделай как на этом сайте» по скриншоту не работает: модель видит пиксели, а не `rgba(0,0,0,.18)`, `blur(2px)` и `mask-image`. Инструмент снимает настоящие значения и складывает их в поля схемы.

## Запуск

```bash
node tools/capture/cli.mjs --url https://guns.lol/romash_10 --slug guns-romash
node tools/capture/compare.mjs --slug guns-romash
```

`--url` — страница профиля. Остальное:

| Флаг | Смысл |
|---|---|
| `--slug` | имя пресета и папки ассетов, по умолчанию `площадка-ник` |
| `--viewports` | `desktop,phone`, по умолчанию оба |
| `--open <css>` | селектор кнопки входа, если автоклик не сработал |
| `--open-wait` | пауза после входа, мс (2500) |
| `--timeout` | таймаут навигации, мс (45000) |
| `--headed` | показать браузер: нужно для Cloudflare и Vercel Checkpoint |
| `--full` | снимать страницу целиком, а не вьюпорт |
| `--no-record` | не записывать canvas |
| `--out` | каталог отчёта, по умолчанию `data/capture/<slug>` |

Результат:

- `schema/presets/<slug>.v1.json` — пресет, проверенный по `schema/profile.v1.schema.json`;
- `web/public/demo/<slug>/` — скачанные шрифты, картинки, курсоры, медиа;
- `data/capture/<slug>/` — `report.json`, скриншоты обоих вьюпортов, запись canvas, `reference.html`, `styles.css`, `unmapped.json`, `README.md`.

Пресет импортируется в `/admin` обычным импортом профиля.

## Проверка точности

```bash
npm run build
node tools/capture/compare.mjs --slug guns-romash --threshold 4
```

Инструмент поднимает локальный сервер, публикует пресет, снимает те же два вьюпорта и считает расхождение через `pixelmatch`. Код возврата `1`, если расхождение выше порога. Диффы и разбивка по зонам — в `data/capture/<slug>/diff/`.

`--mask role[:id]` закрашивает серым динамичную зону (часы, счётчик). Помните: полноэкранный `canvas` закрасит весь кадр — его лучше оставлять в подсчёте.

Порог зависит от площадки. Ориентир с живого прогона `guns.lol/romash_10`: desktop 3.1 % при пороге 4, phone 8.8 % — там сайт меняет раскладку ссылок на иконки, и пресет с одной раскладкой её не повторит. Для мерцающих фонов маскируйте зону (`--mask media`) и поднимайте порог до 12, а не подгоняйте стили под шум.

## Что переносится, а что нет

| Слой | Как берётся |
|---|---|
| DOM и структура | `reference.html` без скриптов, `dom.raw.html` как есть |
| Геометрия, цвета, размытие, радиусы, тени | computed-стили каждого найденного элемента и его `::before`/`::after` |
| Каскад и медиазапросы | `CSS.getMatchedStylesForNode`, `CSS.getMediaQueries` |
| CSS-токены площадки | все `--*` переменные у элемента и предков |
| Шрифты, картинки, видео, курсоры | сетевой перехват, локальные копии по хешу содержимого |
| Canvas и WebGL | запись `<canvas>` в `.webm` + пометка в `unmapped.json` |
| Поведение (наведение, звук, лирика) | не снимается, переносится по исходникам вручную |

Автоматически в пресет попадают: цвета, стекло, ширина и радиус карточки, шрифт и размеры, аватар, ссылки с платформами, фон, splash, курсор, частицы (как «есть canvas»), аудио. Остальное — в `unmapped.json` с причинами: псевдоэлементы, сырые CSS-свойства, токены, canvas, шрифты.

## Ограничения

- Снимается одно состояние страницы. `:hover`, `:active`, фокус, прокрученные секции и второй экран — нет.
- Тип частиц на `canvas` угадывается (`stars`), сам эффект надо переносить из исходников.
- Шрифты сохраняются локально, но их лицензия проверяется человеком.
- Тени, `filter`, `mask-image`, градиенты карточки сохраняются только в отчёте: в схеме для них нет полей.
- `file://` работает, но шрифты на таких страницах браузер может не отдать.

## Правовое

Значения CSS и раскладка на практике не защищаются: копировать можно. Проверяйте лицензии шрифтов (OFL разрешает редистрибуцию, многие бесплатные каталоги — нет), лицензии JS-библиотек (MIT — оставить уведомление) и права на картинки/видео владельца профиля. `unmapped.json` помечает шрифты и курсоры как «проверить лицензию».

## Тесты

```bash
npm run test:capture
```

Тесты гоняют инструмент на локальной фикстуре `fixtures/profile.html` (стекло, градиентный ник, псевдоэлемент, canvas, звук, свой курсор) и проверяют замеры, ассеты, схему, отчёт и то, что сверка действительно ловит подмену цветов.
