# Каталог оформлений, эффектов и архитектуры bio-платформ

Сводный разбор четырёх публичных bio-конструкторов (`guns.lol`, `btw.bio`, `mychar.gg`, `vaults.lol`), выполненный в живом браузере 25 ноября 2026 года. Цель — собрать в одном месте проверенные паттерны визуала, CSS/DOM/Canvas-механики и превратить их в модульную карту возможностей для open-source self-hosted конструктора `bio`.

## 3. Сводный каталог эффектов и модулей (что переносим в `bio`)

Главная цель — **дать большой выбор оформления**, чтобы владелец мог собрать любой из популярных стилей (минималистичную визитку, тёмное/светлое стекло, cardless-сцену над видео, bento-дашборд или split-экран), но при этом каждая тяжёлая или специфическая деталь оставалась **опциональным тумблером**.

### 3.1. Раскладки (Layout Presets) поверх единых данных
1. **`compact` / `classic` (Старт первого релиза из PR #1):** одна центрированная или горизонтальная (аватар слева) карточка с регулируемой шириной (`380–700px`), скруглением, рамкой, размытием, опциональным выступающим аватаром и верхним баннером с затуханием (`mask-image`).
2. **`transparent` (Cardless):** прозрачный контейнер (`alpha: 0`, `blur: 0`) поверх медиа-сцены; читаемость обеспечивается свечением текста/иконок и градиентной подложкой фона.
3. **`float` / `detached`:** шапка профиля, блок ссылок/виджетов и аудиоплеер разделяются на отдельные стеклянные карточки с зазором и общим параллаксом.
4. **`bento` / `asymmetric`:** 2-колоночная сетка карточек или свободная привязка блоков по углам/левому краю (`lekker`, `mercury`, `hypnotic`).
5. **`cinematic-split`:** разделение экрана на 2 половины (прямой или диагональный `clip-path` с одной стороны под сцену/видео/частицы, с другой под профиль; на мобильном — вертикальный стек).
6. **`sections` (Портфолио):** 2–4 полноэкранные секции с плавным переключением и индикатором точек справа.
7. *(Опционально на перспективу)* **многостраничность** (`/`, `/2`, `/3`) с переключателем внизу.

### 3.2. Вход и разблокировка аудио (Splash)
- **Режимы:** `none` (мгновенный показ — по умолчанию для чистых визиток), `blur-curtain`, `radial-dark`, `slit-curtain` (вертикальная шторка `vaults.lol/bias`).
- **Задержка карточки (`card-wait`):** опция показать сначала 1–2 с фоновое видео, а затем запустить вход карточки (`rise`, `blur`, `flip`, `unfold`, каскад блоков).
- **Доступность:** семантическая `<button>` в фокусе с клавиатуры (`Enter`/`Space`), запуск `<audio>`/`AudioContext` по жесту, **раздельная пауза** для фонового видео и музыки (требование PR #1).

### 3.3. 4-слойный фон и частицы
1. **Слой базы:** сплошной цвет / линейный или радиальный градиент.
2. **Медиаслой:** изображение / WebP / `<video loop muted playsinline>` (с `poster`, фолбэком при ошибке загрузки, `contain: strict` и ползунком `blur` + `opacity`).
3. **Затемнение и текстуры:** `--dim`, нижний градиентный фейд под читаемость текста, точечная сетка, сканлайны, анимированный CSS film-grain (`bgfx-grain`), виньетка.
4. **Canvas-частицы (единый слой `pointer-events: none`):** снег, дождь (прямой/диагональный), лепестки сакуры, летающие угли/искры, звёзды; отключаются при `prefers-reduced-motion: reduce`.

### 3.4. Карточка, цвета и типографика
- **Цветовая система (минимум ручных полей):** выбор `accent`, `text`, `cardBg` + `cardAlpha` + `cardBlur` + `cardRadius` + `profileScale`; производные цвета текста (`60%`, `40%`), границы и блики считаются автоматически через `color-mix(in oklab / srgb, ...)`.
- **Вырез под аватар в баннере:** CSS `mask-image: radial-gradient(...)`, корректно работающий на стеклянном фоне.
- **Эффекты имени и био:** `none`, `glow`, `gradient`, `glitch` (CSS `clip-path`), `wave` (CSS-задержка `--i` на `<span>`), `typewriter` (курсор `|` или блок), `scramble`, анимированный `<title>` вкладки, опциональный оверлей искр поверх ника (лёгкий CSS/SVG/`<canvas>` слой по умолчанию + возможность загрузить свой оверлей).
- **Шрифты:** набор проверенных self-hosted `.woff2` (`Onest`, `Inter`, `Pixelify Sans`, `Creepster`, `Lobster`, `Audiowide`, `Rajdhani`, `Russo One`, `Teko`, `Chillax`) + загрузка собственного шрифта владельца без зависимости от внешних CDN.
- **3D-наклон и эффекты иконок:** `perspective(950px) rotateX/Y` с ограничением угла (`±10–12deg`) только на `@media (hover: hover) and (pointer: fine)`; опциональные эффекты иконок (`glow`, `pulse`, `bounce`, `neon` 4-stop `drop-shadow`, `grayscale` капсула бейджей).

### 3.5. Курсоры, аудио и виджеты (включаются по желанию)
- **Курсоры:** системный, загруженный PNG/CUR (`<= 32×32px`), canvas-след (точка/искры/дым), опциональный спрайтовый питомец (`oneko`).
- **Аудио:** угловая кнопка + ползунок громкости **или** отсоединяемая карточка плеера с обложкой и перемоткой (один или несколько треков), опциональное Web Audio кольцо `viz-ring` вокруг аватара и синхронизированная лирика (`.lrc` / `lrclib.net`).
- **Виджеты и блоки:**
  - **Трекер просмотров (и кликов) по желанию:** встроенный локальный подсчёт на своём сервере `bio` (без Turnstile и сторонней аналитики), флаг показа бейджа просмотров на странице и сводка в `/admin`.
  - **Собственные автономные блоки:** ссылки (рядом иконок или списком пилюль), кнопки копирования (Discord-тег, email, кошелёк), локальные часы владельца по IANA-таймзоне (показывают разницу с временем посетителя без API), теги-пилюли (`.ptag`), блок железа/Setup, любимые игры, галерея/клипы, FAQ/цитата/гостевая книга.
  - **Внешние интеграции (фаза 3, с graceful fallback):** Discord Presence (Lanyard / бот), Last.fm / Spotify, GitHub / Twitch / YouTube.
- **Без лишнего шума:** никаких принудительных промо-баннеров платформы в футере, глобальных рейтингов или сторонней рекламы.

## 4. Как перенести это в стек `bio` (Rust + Axum, Svelte + TS)

1. **Единая версионированная схема `profile.v1.json`:**
   - Внутри хранятся: `layout`, `theme` (токены цвета/стекла/масштаба), `background` (4 слоя), `entry` (splash + задержка), `typography` (шрифт + эффекты ника/био), `cursor`, `audio`, `analytics` (`trackViews`, `showViewsBadge`), `blocks[]` (упорядоченные модули контента).
   - Одна и та же схема используется и в `/admin` (Svelte live-preview + импорт/экспорт скинов в 1 клик + редактирование с помощью ИИ), и на сервере (`Rust + Axum`).
2. **Серверный рендер + минимальный клиентский JS:**
   - Axum отдаёт готовую HTML-страницу на `/` с инлайн `<style>:root { ... }</style>` и классами-модификаторами — карточка отрисовывается мгновенно, без скачка стилей.
   - Клиентские скрипты (`tilt.js`, `splash-audio.js`, `fx-canvas.js`, `textfx.js`, `viz-ring.js`, `cursor.js`) подключаются **условно**, только если соответствующая опция включена в `profile.v1.json`.
