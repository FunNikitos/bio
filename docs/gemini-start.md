# Старт Gemini 4 Hydrogen в bio

Открой корневую папку репозитория в Google Antigravity, выбери Gemini 4 Hydrogen и отправь текст ниже. Последнюю строку можно заменить конкретной задачей.

## Промт

```text
Ты работаешь вместе с Codex над проектом bio. Прочитай корневые AGENTS.md и README.md. Проверь статус Git, список рабочих каталогов, свежие коммиты и заметки docs/progress. Если подключён GitHub, сверься с origin и открытыми pull request по моей задаче.

Перед правками выясни, что уже принято, что в работе и какие файлы затронет твоя задача. Готовую функцию проверь. Начатую продолжай по записи о передаче. Для новой задачи создай свою ветку и рабочий каталог по правилам проекта. Учитывай решения и незакоммиченные изменения другого участника.

При сдаче назови ветку, хеш коммита, что изменилось для пользователя, как это проверено и что осталось. Обнови заметку задачи, чтобы Codex мог продолжить с этого места.

Моя задача на этот запуск — ознакомься с состоянием проекта и кратко опиши его. К разработке приступишь, когда я дам конкретную задачу.
```

## Инструменты

| Что делать | Инструмент |
|---|---|
| Читать и менять код, смотреть историю, запускать проверки | Редактор и терминал Antigravity, локальный Git. Команды проекта бери из файлов текущей ветки. |
| Передать работу между компьютерами | GitHub. Ветка показывает коммиты, issue фиксирует исполнителя и задачу, pull request показывает предложенные изменения. Для GitHub CLI нужна авторизация. |
| Посмотреть страницу в настольном и мобильном размерах | Команда `/browser` в Antigravity. Для диагностики загрузки медиа и производительности подходит Chrome DevTools MCP. |
| Повторять сценарии и сравнивать скриншоты своей страницы | Playwright Test, когда появится интерфейс. Playwright MCP пригодится для интерактивного управления браузером агентом. |
| Сверстать по собственному макету | Figma MCP при наличии доступного файла Figma. |

Документация: [правила проекта в Antigravity](https://antigravity.google/docs/rules), [браузер](https://antigravity.google/docs/commands/browser/), [подключение MCP](https://antigravity.google/docs/mcp), [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp), [Playwright](https://playwright.dev/docs/test-snapshots), [Playwright MCP](https://github.com/microsoft/playwright-mcp), [Figma MCP](https://developers.figma.com/docs/figma-mcp-server/).
