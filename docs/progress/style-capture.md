# Экстрактор оформления сайта → пресет `profile.v1`

DeepSeek V4 · 27 ноября 2026 · ветка `task/style-capture`. Базовая ветка — `task/bio-builder-v1`, потому что схема `profile.v1`, `themeCss.ts` и импорт пресетов живут там, а в `main` их ещё нет.

## Цель

Убрать ручное «угадывание» при переносе чужого оформления. Пресеты вида `romash_10` собраны по скриншотам, поэтому расходятся с оригиналом. Нужен воспроизводимый путь: живой профиль → замеры → `schema/presets/<slug>.v1.json` + локальные ассеты + эталонные скриншоты и проверка расхождения.

По решению владельца: и статика, и JS-эффекты; допуск пиксель-в-пиксель на двух вьюпортах; ассеты и шрифты скачиваются локально в репозиторий.

## Что сделано

`tools/capture/` — самостоятельный Node-инструмент на Playwright, без правок `web/`, `server/` и схемы.

| Файл | Назначение |
|---|---|
| `cli.mjs` | аргументы, навигация, снятие splash, CDP-стили, отчёт, запись пресета |
| `anchors.mjs` | поиск ролей по геометрии и computed-стилям, снимок стилей, `::before`/`::after`, `--*` |
| `assets.mjs` | перехват сети, локальные копии по хешу содержимого, переписывание URL |
| `snapshot.mjs` | `reference.html` без скриптов и `dom.raw.html` как есть |
| `record.mjs` | запись `<canvas>` через `captureStream` + `MediaRecorder` |
| `mapping.mjs` | замеры → поля схемы, `unmapped.json`, оценки уверенности |
| `preset.mjs` | слияние с базой, нейтральные значения, проверка Ajv |
| `compare.mjs` | локальный рендер пресета, `pixelmatch`, разбивка по зонам |
| `extract-defaults.mjs` | `base-profile.json` из `createDefaultProfile()`, чтобы не держать вторую копию дефолтов |

Роли (`root`, `card`, `name`, `username`, `bio`, `avatar`, `links`, `tag`, `player`, `media`, `canvas`, `splash`) ищутся эвристиками по положению, размеру, тегу и стилям, а не по селекторам площадки, поэтому инструмент не привязан к guns.lol.

Команда:

```bash
node tools/capture/cli.mjs --url <профиль> --slug <slug> [--headed]
node tools/capture/compare.mjs --slug <slug> [--threshold N] [--mask role[:id]]
```

Выход: пресет, прошедший `schema/profile.v1.schema.json`; `web/public/demo/<slug>/`; `data/capture/<slug>/` с отчётом, обоими скриншотами, CSS, `unmapped.json` и диффами.

## Решения

- Поиск по геометрии, а не по DOM площадки: разметка guns.lol, btw.bio и mychar.gg разная и меняется.
- База пресета берётся из `createDefaultProfile()`; тест падает, если `base-profile.json` разошёлся с кодом.
- Сплэш снимается кликом по триггеру, затем по оверлею, затем принудительным `display:none`; кадр splash сохраняется до клика и подставляется в якоря.
- Телефон снимается с `deviceScaleFactor: 2`: `setViewportSize` сбрасывает DPR в 1, иначе вьюпорты сравнивались бы в разном масштабе.
- Непереносимое не выдумывается: неоднозначные поля получают `low`/`medium` и строку в `unmapped.json`.

## Проверки

- `node --test "tools/capture/test/*.test.mjs"` — 21/21.
- `npm test` (check, web, server, capture) — зелёный. В `test:capture` пришлось перейти с каталога на glob: на Windows `node --test <dir>` не резолвится.
- Фикстура: стекло `opacity 42`/`blur 18`/`radius 28`, ширина 620, акцент `#c084fc`, градиентный ник, 3 ссылки, круглый аватар 112, локальные курсор и звук, splash «click to enter...». Сверка фикстуры: desktop 3.7 %, phone 7.6 %, подмена цвета ловится.

## Что выяснилось на живом сайте

- Телефон на guns.lol — другая раскладка: вместо пилюль идут четыре иконки в ряд и счётчик просмотров. Пресет хранит одну раскладку ссылок (`pills`), поэтому на телефоне расходятся именно ссылки, медиа и splash. Это ограничение схемы, а не ошибка замеров.
- Фон — видео/канвас со звёздами; частицы угаданы как `stars`. Покадровое мерцание звёзд даёт неустранимый процент даже при верной геометрии.
- Тень, `mask-image` и градиенты карточки в схеме полей не имеют и остаются только в отчёте.
- Шрифт Satoshi сохранён локально; лицензию надо проверить перед публикацией (помечено в `unmapped.json`).

## Передача

Запускать `compare` с порогом 4 для desktop и 12 для phone; для мерцающих фонов дополнительно маскировать зону: `--mask media`. Ручной перенос частиц, `:hover`, звука и лирики остаётся человеку. Перед публикацией чужого профиля — проверить лицензии шрифтов, картинок и музыки.
