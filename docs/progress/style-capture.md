# Экстрактор оформления сайта → пресет `profile.v1`

DeepSeek V4 · 27 ноября 2026 · ветка `task/style-capture`. Базовая ветка — `task/bio-builder-v1`, потому что схема `profile.v1`, `themeCss.ts` и импорт пресетов живут там, а в `main` их ещё нет.

## Цель

Убрать ручное «угадывание» при переносе чужого оформления. Пресеты вида `romash_10` собраны по скриншотам, поэтому расходятся с оригиналом. Нужен воспроизводимый путь: живой профиль → замеры → `schema/presets/<slug>.v1.json` + локальные ассеты + эталонные скриншоты и проверка расхождения.

По решению владельца: и статика, и JS-эффекты; допуск пиксель-в-пиксель на двух вьюпортах; ассеты и шрифты скачиваются локально в репозиторий.

## Область правок

Только новый каталог `tools/capture/` и его тесты. Файлы `web/`, `server/`, `schema/profile.v1.schema.json` не меняются, кроме добавления новых пресетов как результата работы инструмента.

## План

1. Захват: Playwright, снятие splash, два вьюпорта, computed-стили (включая `::before`/`::after`), кастомные `--*` переменные, `@media`, DOM-снимок, скриншоты, запись `<canvas>` через `captureStream`.
2. Ассеты: перехват сетевых ответов, локальное сохранение с хешами, переписывание URL в снимке.
3. Маппинг замеров в `profile.v1` по `docs/research/live-settings-matrix.md`; неоднозначные поля — в `unmapped.json`.
4. Проверка точности: рендер нашего пресета, скриншоты на тех же вьюпортах, `pixelmatch`-диff и порог расхождения.
5. Тесты на локальной фикстуре без сети.

## Ограничения заранее

- Canvas-эффекты переносятся не автоматически: инструмент фиксирует запись и исходный JS, ручной перенос остаётся.
- Vercel Security Checkpoint и Cloudflare требуют иногда ручного прохода — предусмотрен `--headed`.
- Шрифты: лицензия проверяется вручную, в отчёте фиксируется источник.
