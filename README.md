# bio

bio — конструктор персональной страницы для установки на собственный сервер. Цель первого релиза — дать владельцу готовый комплект, с которым можно подключить домен, открыть редактор в браузере и опубликовать профиль с аватаром и ссылками. Исходники можно будет менять самостоятельно или с помощью ИИ.

Проект находится на этапе проектирования первого релиза. [Сценарий установки и критерии готовности](docs/progress/self-host-first.md) описывают, как будет устроен путь от GitHub до собственного био.

## Пример карточки

[Карточка 952](examples/952/index.html) — готовая музыкальная визитка с портретом и видеофоном. Для просмотра скачайте проект и откройте `examples/952/index.html` в браузере. Для размещения на статическом хостинге скопируйте содержимое `examples/952/` целиком.

## Ход разработки

Принятые изменения видны в истории ветки `main`. В [заметках по задачам](docs/progress/) участники записывают решения, результаты проверок и открытые вопросы.

Участникам проекта пригодятся [правила совместной работы](AGENTS.md) и [стартовый промт для Gemini](docs/gemini-start.md).
